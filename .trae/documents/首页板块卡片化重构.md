# 首页板块卡片化重构 实施计划

## Summary

对首页（Discover.jsx）做一次板块级重构：**「今日推荐」轮播完全保留不动**，将现有的「分类」内联板块与「AI 快讯」横滑条替换为一个**标准化方框卡片网格**（首批 4 张卡片：知识分类 / AI快讯 / 今日新闻 / xxx 预留卡）。「今日新闻」新建一个纯前端页面，复用 `/api/news` 数据按日期分组展示。所有卡片通过一个 props 驱动的通用组件实现，支持后续仅改 props 即可更名/换目标。**零后端改动。**

## Current State Analysis

首页（`frontend/src/pages/Discover.jsx`）当前板块顺序：

1. 顶栏（品牌 + 搜索）
2. **今日推荐** — `carousel` 轮播（`<Link to="/article/:id">`，带箭头/圆点/触摸滑动）→ **保留不动**
3. **分类** — `chips` 分类筛选 + 内联文章预览列表（`row-list`，`list.slice(0,3)`）+「查看全部」链接 → **本次移除**
4. **专题** — `promo` 卡片（跳 `/topic/:id`）→ **保留不动**
5. **AI 快讯** — `module-head-row` + `news-strip` 横滑条（`news-card`）→ **本次移除（改为卡片）**
6. **我的收藏** — `saved-card` → **保留不动**

关键现状确认：

- 已有样式范式可复用：`news-card`（边框+surface+shadow-low+r-lg+hover 高亮）、`saved-card`、`promo`，全部只用 CSS 变量，无裸色值。
- `news-strip / news-card / news-source / news-title / module-head-row / module-more` 这组类**只在 Discover.jsx 使用**，随板块移除后属于死 CSS，需连带清理（遵守 AGENTS.md「删除组件连带清死 CSS」规则）。
- `news-item / news-item-top` 被 `News.jsx` 与 `NewsDetail.jsx` 复用 → **保留**，新页面「今日新闻」直接复用。
- 设计 tokens：`--surface/--sunken/--line-strong/--accent-soft/--accent-strong/--r-lg/--shadow-low/--glow-accent/--dur-normal/--ease` 等均已存在，无需新增 token。
- 路由现状：`/news`（快讯列表）、`/article/:id`、`/topic/:id`、`/articles`（全部文章，自带分类筛选）均已存在。

## Proposed Changes

### 1. 新建通用卡片组件 `frontend/src/components/ModuleCard.jsx`（新文件）

props 驱动的标准化方框卡片，一次开发多处复用：

```jsx
import { Link } from 'react-router-dom'
import { CaretRight } from '@phosphor-icons/react'

export default function ModuleCard({ title, subtitle, icon: Icon, to }) {
  return (
    <Link to={to} className="module-card">
      <span className="module-card-ico"><Icon size={21} /></span>
      <span className="module-card-title">{title}</span>
      {subtitle && <span className="module-card-sub">{subtitle}</span>}
      <span className="module-card-go"><CaretRight size={12} /></span>
    </Link>
  )
}
```

- 整卡是 `<Link>`，点击即跳转，满足「点击卡片触发页面重定向」需求。
- `xxx` 预留卡只需改调用处 4 个 props（title/subtitle/icon/to）即完成更名与功能适配——满足扩展性要求。
- 图标走 Phosphor，21px 档（与设计规范一致）。

### 2. 首页 `frontend/src/pages/Discover.jsx` 改造

**移除**（连同对应 state / useEffect / import）：

- 「分类」整块：`chips` 筛选、`list.slice(0,3)` 内联列表、「查看全部」链接；对应移除 state `cats / cat / list / listLoading` 及两个 `useEffect`、`getCategories / getArticles` 的 import。
- 「AI 快讯」整块：`module-head-row` + `news-strip` + `news-card`；`getNews` 的 import 同时移除（首页不再需要 news 数据）。
- `Books` 图标保留（`empty-art` 空态仍在用）。

**新增**：在「今日推荐」轮播区块之后、专题区块之前，插入卡片网格模块：

```jsx
{!loading && !error && (
  <>
    <p className="sub-eyebrow module-head">快捷入口</p>
    <div className="module-grid enter" aria-label="快捷入口">
      <ModuleCard title="知识分类" subtitle="按主题浏览文章" icon={Books} to="/articles" />
      <ModuleCard title="AI 快讯" subtitle="每日行业动态" icon={Newspaper} to="/news" />
      <ModuleCard title="今日新闻" subtitle="按日期翻阅快讯" icon={CalendarBlank} to="/news-today" />
      <ModuleCard title="更多内容" subtitle="预留入口 · 后续接入新功能" icon={Sparkle} to="/articles" />
    </div>
  </>
)}
```

- 新增 import：`ModuleCard`、`Newspaper / CalendarBlank / Sparkle`。
- 第 4 张卡即「xxx」预留位，以可配置占位卡呈现（当前跳 `/articles`），后续改 props 即可。
- 网格加 `.enter` 参与滚动入场动画（`useReveal` 自动接管，reduced-motion 兜底不受影响）。
- 板块标题复用现有 `sub-eyebrow module-head`。

### 3. 新建页面 `frontend/src/pages/NewsToday.jsx`（新文件，纯前端）

- 数据：`getNews(50)`（复用现有接口，零后端改动）。
- 布局：`page-head`（标题「今日新闻」+ 副题）、加载骨架（复用 `sk-row`）、错误态（复用 `error`）、空态（复用 `empty`，`Newspaper` 图标）。
- 内容：按 `published_at` 日期分组，组头文案规则：**今天 / 昨天 / M月D日**（`toLocaleDateString('zh-CN', { month: 'numeric', day: 'numeric' })`），无 `published_at` 的归入「其他」。
- 列表项复用现有 `.news-item` 样式（`<Link to={'/news/' + n.id}>`，含 source tag、标题、摘要）。
- 日期分组在组件内做纯函数（`groupByDate`），不引第三方库。

### 4. 路由与底栏 `frontend/src/App.jsx`

- import `NewsToday`。
- 新增 `<Route path="/news-today" element={<NewsToday />} />`。
- `hideTab` 条件追加 `location.pathname.startsWith('/news-today')`（与 `/news/` 一致隐藏底部导航）。

### 5. 样式 `frontend/src/index.css`

**新增**（全部只用 CSS 变量，无裸色值，样式对齐 `news-card` 范式）：

- `.module-grid`：`display: grid; grid-template-columns: repeat(2, 1fr); gap: 12px; margin-top: 12px;`（`--max-app` 480px 内两列布局，天然响应式）。
- `.module-card`：`position: relative; display: flex; flex-direction: column; gap: 8px; padding: 14px; border: 1px solid var(--line-strong); border-radius: var(--r-lg); background: var(--surface); box-shadow: var(--shadow-low); text-decoration: none; color: inherit; transition: border-color var(--dur-normal) var(--ease), box-shadow var(--dur-normal) var(--ease);`
- `.module-card:active`：轻微按压（`transform: translateY(1px)`，对齐 `.chip:active`）。
- hover 态包进 `@media (hover: hover) and (pointer: fine)`，与 `:focus-visible` 同效果：`border-color: var(--accent-tint)` 增强 + `box-shadow: var(--glow-accent)`（同 `.news-card` 范式）。
- `.module-card-ico`：44px 方盒、`border: 1px solid var(--accent-tint)`、`background: var(--accent-soft)`、`color: var(--accent)`、`border-radius: var(--r-md)`（对齐 `.saved-ico` 范式）。
- `.module-card-title`：`font-heading` 15px 700。
- `.module-card-sub`：`font-body` 12px `var(--text-2)`。
- `.module-card-go`：右下角 `var(--accent-strong)`，`font-mono` 11px。
- `.news-today-group`：日期组头，`font-mono` 12px 700 `var(--accent-strong)` 上边距分隔。

**删除**（死 CSS，仅 Discover 使用，已确认无其他引用）：`.news-strip`、`.news-card`、`.news-source`、`.news-title`、`.module-head-row`、`.module-more`。

### 6. 不动的东西

- 今日推荐轮播（视觉/交互/位置/优先级）——零改动。
- 专题 `promo`、我的收藏 `saved-card`。
- 后端全部代码、`api.js`、路由数据接口。
- 设计 DNA 与 `:root` token（无新增 token，无裸色值）。

## Assumptions & Decisions

1. 卡片网格位于「今日推荐」之后、「专题」之前，标题为「快捷入口」。
2. 「今日新闻」为纯前端页面，复用 `/api/news` 按日期分组（今天/昨天/M月D日），不改后端。
3. 「xxx」预留卡以可配置占位卡形式展示（标题「更多内容」、跳 `/articles`），结构上改 props 即可更名换目标。
4. 网格两列布局（移动端优先，`--max-app` 限制下恒为两列）。
5. 移除内联文章预览后，完整列表仍可从 `/articles` 页访问（该页自带分类筛选）。

## Verification

1. `cd frontend && npx vite build` 无报错（必跑）。
2. 浏览器人工核验：
   - 首页「今日推荐」轮播保持原样、位置仍居首。
   - 卡片网格 4 张卡均能正确跳转：知识分类→`/articles`、AI快讯→`/news`、今日新闻→`/news-today`、更多内容→`/articles`。
   - `/news-today` 按「今天/昨天/M月D日」正确分组，空态/加载态正常，底栏隐藏。
   - 移动端与宽屏下网格两列对齐、卡片内文字不溢出。
3. 自查项（AGENTS.md 要求）：
   - 新增/删除的 JSX 类名与 CSS 一一对应（无缺失、无死类）。
   - 新增样式无裸色值（全部 `var()`），色值溯源可归入 DNA 色板。
   - 交互元素同时具备 `:hover`（`@media (hover: hover) and (pointer: fine)` 内）与 `:focus-visible`。
   - `.enter` 内容不卡在 `opacity:0`，`prefers-reduced-motion` 降级不受影响。
